# CarbonTrace: System Workflow

- **Natural Language Input:** Users log daily activities (transport, food, energy) using simple text descriptions instead of complex forms.
- **Automated AI Calculation:** **Google Gemini** parses the input, extracts key metrics, and computes CO2 emissions using integrated emission factors.
- **Secure Cloud Storage:** Activity history and emission statistics are securely managed in **Cloud Firestore** for private, long-term tracking.
- **Visual Analytics:** A dynamic dashboard provides real-time insights through interactive charts and trend analysis.
- **Blockchain Verification:** A simulated "commit" feature generates immutable transaction hashes, demonstrating transparent and tamper-proof environmental accountability.
